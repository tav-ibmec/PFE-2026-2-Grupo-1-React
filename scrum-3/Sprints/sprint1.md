# Sprint 1 — Início do projeto React e definição das atribuições

## Objetivo da Sprint

Iniciar o projeto React, dividir as atribuições entre os integrantes e organizar o prazo e as mudanças solicitadas para a entrega de 13/11/2026.

## Atividades planejadas

- Enviar os documentos do repositório anterior para o repositório React.
- Dividir as atribuições de cada integrante em frentes de trabalho.
- Registrar o prazo de entrega de 13/11/2026.
- Registrar a nova página de Fisioterapia no Início.
- Registrar as alterações solicitadas e a necessidade de aproximar a interface do protótipo.
- Registrar que o agendamento está em aberto até a confirmação do professor.
- Iniciar a estrutura do projeto em React.

## Distribuição das atividades

- **Estrutura e publicação:** início do projeto em React e das rotas das páginas.
- **Início (antigo Hub):** planejamento da página inicial e do card da Fisioterapia.
- **Componentes comuns:** planejamento do cabeçalho fixo, do menu, do hero e do rodapé.
- **Seções de conteúdo:** planejamento das seções das landing pages.
- **Página de Fisioterapia:** levantamento do conteúdo da nova página.
- **Contato e agendamento:** acompanhamento da decisão do professor sobre o agendamento.
- **Equipe:** atualização da documentação Scrum no repositório React.

## Resultado esperado

Ter as atribuições definidas, o prazo e as mudanças registrados e a estrutura do projeto React iniciada, preparando o desenvolvimento dos componentes.

## Critérios de conclusão

- [x] Documentos do repositório anterior enviados ao repositório React.
- [x] Atribuições definidas para todos os integrantes.
- [x] Prazo de entrega registrado.
- [x] Página de Fisioterapia e alterações solicitadas incluídas no Product Backlog.
- [x] Pendência do agendamento registrada.
- [x] Estrutura do projeto em React iniciada.

## Status da Sprint

A Sprint foi concluída em 06/11/2026. O grupo realizou a reunião de divisão das atribuições, enviou os documentos do repositório anterior para o repositório React e registrou o prazo, a página de Fisioterapia, as alterações solicitadas e a pendência do agendamento.

## Impedimentos e pendências

- O agendamento depende da confirmação do professor e permanece em aberto.
